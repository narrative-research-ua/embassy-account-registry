# Реєстр акаунтів російських дипломатичних установ у X

Статична версія реєстру для публікації через GitHub Pages.

## Файли

- `index.html` — готова сторінка з пошуком, фільтром і сортуванням.
- `accounts.csv` — 41 акаунт, включений до вибірки.
- `excluded.csv` — шість країн, не включених до вибірки.
- `.nojekyll` — вимикає обробку Jekyll.

## Як опублікувати

1. Створіть на GitHub новий публічний репозиторій, наприклад `embassy-account-registry`.
2. Завантажте в корінь репозиторію всі файли з цієї папки.
3. Відкрийте **Settings → Pages**.
4. У блоці **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку **main**, папку **/(root)** і натисніть **Save**.
6. Після публікації сторінка буде доступна за адресою:
   `https://<назва-акаунта-або-організації>.github.io/embassy-account-registry/`

Для оновлення реєстру замініть `index.html` і CSV-файли в тому самому репозиторії.
